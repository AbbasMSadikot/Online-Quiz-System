## Contribution and evidence rules

- Implement against the submitted SRS, SAD, and Test Plan; open pull requests for code changes and have a repository owner review them.
- Link each change to its requirement/backlog issue and record the verification performed.
- Capture the one-minute Sprint 1 and two-minute Sprint 2 working-product demos, and upload the approved videos to the repository.
- Add screenshots and artifacts to the matching evidence folder; do not mark placeholders or planned work as completed.
- Record deviations with the source document, affected requirement/design/test, reason, and disposition.
