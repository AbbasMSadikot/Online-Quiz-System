# Requirements Engineering

This folder contains the working requirements register, Requirements Traceability Matrix (RTM), and deviation log. The submitted [SRS.pdf](../1-SRS-and-WBS/SRS.pdf) is authoritative; its IDs were checked against the RTM on 30 October 2026.

- [Requirements Traceability Matrix](RTM.md)
- [Deviation and gap log](deviation-log.md)
- Backlog source: [repository issues](https://github.com/AbbasMSadikot/Online-Quiz-System/issues) and the [Online Quiz System project board](https://github.com/users/AbbasMSadikot/projects/1)

The RTM records implemented, open, and blocked requirements. It does not claim incomplete requirements as passed.
